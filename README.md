## 🌐 How to Point `research.gurrspurrs.com` to this GitHub Hub

To connect your custom subdomain (`research.gurrspurrs.com`) directly to this live GitHub Pages repository:

1. Log into your domain registrar (GoDaddy, Cloudflare, Namecheap).
2. Go to **DNS Management** for `gurrspurrs.com`.
3. Add a new **CNAME record**:
   * **Type:** `CNAME`
   * **Name / Host:** `research`
   * **Target / Points To:** `beardedfreedom.github.io`
   * **TTL:** `Auto` (or 300s)
4. GitHub Pages will automatically provision a free Let's Encrypt SSL certificate (`https://research.gurrspurrs.com`) within 10–15 minutes!
